# LegalEase - AI Powered Legal Document Generator

## 📌 Project Overview
LegalEase is an AI-powered platform designed to simplify and automate the creation of legal documents. It helps users generate accurate, customized legal agreements and contracts quickly, reducing time and complexity.

## ✨ Key Features
- **Automated Document Generation:** Easily create agreements, contracts, and legal forms using AI.
- **User-Friendly Interface:** Simple form-based input for customized documents.
- **Time-Saving & Efficient:** Eliminates manual drafting errors and speeds up the workflow.
- **Secure & Organized:** Keeps track of created documents for easy access.
